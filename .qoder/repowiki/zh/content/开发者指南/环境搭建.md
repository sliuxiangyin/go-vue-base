## 项目前置依赖

在开始搭建本地开发环境之前，请确保系统中已安装以下依赖：

- **Go 1.21+**：后端服务使用 Go 语言开发，建议使用 Go 1.24 或更高版本。  
- **Node.js 16+**：前端项目基于 Vue 3 和 Vite 构建，需 Node.js 环境支持。  
- **pnpm**：推荐使用 pnpm 作为前端包管理器，也可使用 npm，但 pnpm 更高效且节省磁盘空间。

可通过以下命令验证环境是否就绪：

```bash
go version
node --version
pnpm --version
```

## 安装依赖

### 安装 Go 模块

在项目根目录执行以下命令，下载 Go 依赖模块：

```bash
go mod download
```

该命令会根据 `go.mod` 文件自动拉取所需依赖，包括 `gofiber/fiber/v2`、`gorm.io/gorm` 等。

### 安装前端依赖

进入 `web` 目录并安装前端依赖：

```bash
cd web
pnpm install
cd ..
```

若未安装 pnpm，可使用 npm 全局安装：

```bash
npm install -g pnpm
```

## 启动开发服务器

项目支持两种开发模式启动方式，推荐使用 `just dev` 命令。

### 推荐方式：使用 just dev 启动

```bash
just dev
```

该命令会设置 `MODE=dev` 环境变量，并执行 `go run main.go` 启动后端服务。

### 手动方式：直接运行 Go 程序

```bash
go run -tags dev main.go
```

此方式等效于 `just dev`，适用于未安装 `just` 工具的环境。

## justfile 构建命令详解

`justfile` 是一个轻量级的构建命令管理工具，用于简化常用操作。项目中定义了以下常用命令：

| 命令 | 说明 |
|------|------|
| `just dev` | 启动开发模式服务 |
| `just build` | 构建前端并生成后端二进制文件 |
| `just build-web` | 仅构建前端项目 |
| `just clean` | 清理构建产物 |
| `just install-web` | 安装前端依赖（注意：当前存在路径拼写错误） |

> **注意**：`justfile` 中 `install-web` 命令存在拼写错误（`cd wen` 应为 `cd web`），建议手动执行 `cd web && pnpm install`。

## 前后端端口与代理机制

### 服务端口

- **后端服务**：运行在 `http://localhost:8080`  
- **前端开发服务器**：运行在 `http://localhost:5173`

### 请求代理机制

前端通过 Vite 的代理功能将 `/api` 开头的请求转发至后端，配置如下：

```ts
// vite.config.ts
server: {
  proxy: {
    '/api': {
      target: 'http://127.0.0.1:8080',
      changeOrigin: true,
      rewrite: (path) => path.replace(/^\/api/, '')
    }
  }
}
```

在开发模式下，所有非 API 请求由前端处理，API 请求被代理到后端，实现无缝联调。

## 常见问题与解决方案

### 1. go.mod 文件解析失败

**问题现象**：执行 `go mod download` 报错，提示模块无法下载。  
**解决方案**：
- 检查 Go 版本是否为 1.21+。
- 设置 GOPROXY 镜像加速：
  ```bash
  go env -w GOPROXY=https://goproxy.cn,direct
  ```

### 2. pnpm 命令未找到

**问题现象**：`pnpm install` 报错 “command not found”。  
**解决方案**：
- 全局安装 pnpm：
  ```bash
  npm install -g pnpm
  ```
- 或使用 npm 替代：
  ```bash
  cd web && npm install
  ```

### 3. 端口冲突

**问题现象**：启动服务时报错 “address already in use”。  
**解决方案**：
- 更改后端端口：在 `.env` 文件中设置 `APP_PORT=8081`。
- 更改前端端口：修改 `vite.config.ts` 中的 `server.port`。

### 4. just 命令未安装

**问题现象**：`just dev` 报错 “command not found”。  
**解决方案**：
- 安装 just 工具：
  ```bash
  # Windows（使用 scoop）
  scoop install just

  # macOS（使用 brew）
  brew install just

  # Linux（使用 cargo）
  cargo install just
  ```
