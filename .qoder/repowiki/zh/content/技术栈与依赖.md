## 后端技术栈

项目后端采用 Go 语言（版本 1.24.0）构建，使用 GoFiber v2.52.0 作为 Web 框架，GORM v1.31.0 作为 ORM 工具，openai-go v1.12.0 用于集成 AI 服务。

GoFiber 框架在 `main.go` 文件中被实例化并用于启动 HTTP 服务器，处理路由和中间件。通过 `fiber.New()` 创建应用实例，并通过 `Listen(":8080")` 启动服务。

GORM 作为数据库 ORM 工具，通过其 `gorm.io/gorm` 模块（v1.31.0）提供数据库抽象层，支持多种数据库驱动。项目中通过 `gorm.io/driver/mysql` 和 `modernc.org/sqlite` 实现对 MySQL 和 SQLite 数据库的支持。

AI 服务集成通过 `github.com/openai/openai-go` 模块（v1.12.0）实现，封装在 `internal/infra/ai/openai.go` 文件中，提供单例模式的客户端访问。

## 前端技术栈

前端采用 Vue 3.5.22 作为核心框架，结合 Vite 7.1.7 构建工具实现快速开发与热重载。TypeScript 5.9.3 提供静态类型系统，增强代码可维护性与开发体验。样式系统采用 Tailwind CSS 4.1.16，通过实用类（utility classes）实现高效 UI 开发。

项目中集成了多个 UI 组件库，包括 `shadcn-vue` 和 `lucide-vue-next`，位于 `web/src/components/ui` 目录下，提供 Alert、Button、Card、Dialog、Input、Tabs 等常用组件，支持模块化导入与主题定制。

## 技术选型考量

### 为何选择 GoFiber 而非标准 net/http

GoFiber 是基于 Fasthttp 构建的高性能 Web 框架，相比标准库 `net/http`，其性能显著提升。GoFiber 提供了更简洁的 API、内置中间件支持（如 CORS）、路由分组、错误处理等特性，极大提升了开发效率。项目中通过 `cors.New()` 启用跨域支持，并通过模块化路由注册机制（`RegisterRoutes`）实现清晰的路由管理。

### Vue 3 的组合式 API 优势

Vue 3 的组合式 API（Composition API）允许开发者通过 `setup` 函数组织逻辑，将相关功能聚合在一起，而非分散在 `data`、`methods`、`computed` 等选项中。这提升了代码的可读性与复用性，尤其适用于复杂组件。结合 TypeScript，提供了完整的类型推断与开发时检查。

### Tailwind CSS 在快速 UI 开发中的作用

Tailwind CSS 采用实用优先（utility-first）的 CSS 方法，通过预定义的类名直接在 HTML 中应用样式，避免了传统 CSS 中的命名困扰与样式冲突。其与 Vite 的深度集成支持 JIT（即时编译）模式，仅生成实际使用的 CSS，显著减小了生产包体积。结合 `class-variance-authority` 和 `clsx` 等工具，实现了可复用的组件变体系统。

## 前后端通信机制

前后端通过 RESTful API 进行通信。前端使用 `axios` 库（v1.13.1）发起 HTTP 请求，与后端 GoFiber 暴露的 `/api` 路由进行交互。后端路由通过 `app.Group("/api")` 统一前缀，由各业务模块注册具体端点。

前端状态管理与路由导航依赖 `vue-router`（v4.6.3），实现基于路径的视图切换与嵌套路由。例如，`/database-chat/:id` 路径对应数据库聊天界面，`/test` 路径下嵌套多个子视图（Home、About、ApiTest 等）。

## 依赖版本兼容性与间接依赖

项目依赖通过 `go.mod` 和 `package.json` 精确管理版本，确保构建可重现。Go 模块使用语义化版本控制，前端依赖使用 `^` 符号允许补丁与次要版本更新。

关键间接依赖包括：
- **数据库驱动**：`github.com/go-sql-driver/mysql`（v1.9.3）用于 MySQL，`modernc.org/sqlite`（v1.39.1）用于 SQLite。
- **工具库**：`github.com/google/uuid`（v1.6.0）用于生成唯一标识，`github.com/joho/godotenv`（v1.5.1）用于加载环境变量。
- **其他**：`filippo.io/edwards25519`、`golang.org/x` 系列工具库等，由主依赖间接引入。

所有依赖均通过模块化管理，避免版本冲突，确保项目稳定性。
