## english_lessons  英语课

| 字段名                   | 类型              | 示例                                                            | 说明                  |
| --------------------- | --------------- | ------------------------------------------------------------- | ------------------- |
| `id`                  | BIGINT UNSIGNED | 1                                                             | 主键                  |
| `title`               | VARCHAR(255)    | *Forrest Gump – Opening Narration*                            | 文章或片段标题             |
| `audio_url`           | VARCHAR(512)    | /audio/forrest_gump_opening.mp3                               | 音频文件路径              |
| `duration`            | FLOAT           | 23.6                                                          | 音频时长（秒）             |
| `content_en`          | TEXT            | 原英文内容                                                         | 原文（完整段落）            |
| `content_zh`          | TEXT            | 中文翻译                                                          | 手动或机器翻译             |
| `semantic_json`       | JSON            | [{"text": "The story", "start": 0.00, "end": 0.65}, ...]      | ✅ 语义意群与时间戳匹配结果      |
| `word_timestamp_json` | JSON            | [{"word": "The", "start": 0.00, "end": 0.25}, ...]            | Whisper 输出的逐词时间戳    |
| `phonetic_json`       | JSON            | [{"word":"Forrest","ipa":"/ˈfɒrɪst/"}]                        | 可选：发音词典             |
| `level`               | TINYINT         | 2                                                             | 难度等级（1~5）           |
| `tags`                | JSON            | ["movie","love","classic"]                                    | 分类标签（支持检索）          |
| `is_public`           | BOOLEAN         | 1                                                             | 是否公开（用于审核或版权控制）     |
| `created_at`          | DATETIME        |                                                               | 创建时间                |
| `updated_at`          | DATETIME        |                                                               | 更新时间                |
